What the critics caught

Six findings worth a teammate's attention. Each one was invisible to the gates — the suite was green through every one of them.

Piece 12 · critic

One missing brace was deleting the leaderboard and the whole prize wall

.eg-trophy shipped without its closing }. Blink supports CSS nesting, so it did not error — it parsed the 63 rules that follow as descendants of a <canvas>, which has no element children. None of them ever matched.

Standings heading
10.8 px (60.5 authored)
Prize wall
a black disc
Wall copies
all 15 at x = −960

It was invisible to every instrument: TypeScript cannot see inside a template literal, ESLint has no CSS rule here, and every screenshot still rendered something. Vitest printed "Could not parse CSS stylesheet" nine times in one file and passed anyway — the suite had been saying so for hours and it read as noise. Now pinned by a brace-balance walk in two files.

Piece 12 · round 5

The frame drops were never main-thread work

Five rounds hunted a stutter at the results screen. Chromium's Long Animation Frame attribution settled it: the cost was backdrop-filter: blur() on a viewport-sized box — the compositor, not our code.

Long frame
61.6 ms
Before render started
60.5 ms
Script over 5 ms
none

That is why every layer-promotion attempt failed, and why our own GPU timer read ~1 ms straight through it — the query measures our context, not the compositor. Three richer replacements were built and all three measured worse than the defect, so the fix removes work instead: render at 1/6 resolution behind the results and let the upscale be the defocus.

Piece 08 · critic

The drivers were helmet balls

Six rounds argued about kart bodywork. Nobody had measured the characters — the half of the piece it is named after.

Head, of the character

Torso + arms + gloves
1.7–4.0 % of the kart

Worse than a look: the rider ships a lean rig, arm pivots, a mouth and blush. At 300 px of body the pose rig animated nothing a player could see. The fix was the right root — the karts were too big for their drivers, not the drivers too small for the frame — and shrinking the bodywork took body pixels up 4.8–7.6×.

Piece 14 · critics

The rider could not hear the water over the midway

The audio panel told players a mix was fine when the on-power cue was inaudible. Round 4 proved every mix it called "sounding" carried a sample — but rendered each with the other four channels at zero, so it answered "does a sample exist", not "can I hear it".

The damning form: the panel warns, advises "press +", and one press clears the warning while leaving the rider 24.5 dB down. The next critic then found the replacement model was validated at one of 14,641 possible mixes and was 1.78 dB optimistic everywhere else — because a single noise buffer feeds the cars, the crowd and the music, so they correlate instead of adding independently.

Piece 16 · critic

The fix for the blurry prize wall was causing it

Round 3 snapped every prize image to the device-pixel grid and reported success. Measured in actual pixels, all fifteen were being resampled — and the snap was the entire cause.

As shipped
15/15 resampled
Snap removed
0/15 — bit-identical

Chromium snaps an image's paint rect in its own local space, so a fractional layout position is already fine — but a transform lands after that snap. And because getBoundingClientRect reports layout plus transform, the guard read the broken case as perfect. Two guards ended up contradicting each other; only one had a control.

Infrastructure

A must-fail test that had never once fired

A test asserting the tool refuses a software GPU adapter was green — because with no server running it died on ERR_CONNECTION_REFUSED, a catch-all dressed that as the "correctly refused" exit code, and its message check matched the tool's own banner, printed before any browser launched.

It was caught within the hour by giving infrastructure aborts their own exit code — a fix made for an unrelated flake. Green in exactly the conditions CI would run in, and it had never demonstrated the thing it existed to prove.

The machine

The loop crashed this workstation five times with 0x119 VIDEO_SCHEDULER_INTERNAL_ERROR before anything read the machine's own distress signals. One crash also rearranged the desktop icons — the display topology drops out during the reset and Windows re-flows the desktop to a smaller grid.

Two guards now sit in front of every browser launch

  • Health. Reads the Windows event log for driver resets and recent bugchecks, and refuses to launch when the machine is in distress. Unknown is not treated as healthy — a failed query admits it rather than returning zero.
  • Rate. A cross-process permit pool caps launches at 20 per minute — 1,200/hour against the 2,970/hour that bugchecked. It waits rather than refusing.

The ledger has since measured this machine sitting at 19 launches against a ceiling of 20, continuously, at full lane count. The guard is doing its job — and that is the reason not to widen the fleet rather than raise the ceiling.

One decision outstanding

These 1,825 tests have never run in CI

prototype-suites.yml's matrix covers two other prototypes and not this one, so the suite only ever runs when a human types the command. That workflow's own header records a previous prototype joining with 25 test files that had never run.

Adding it is one matrix line. The argument for doing it now is the never-fired must-fail test above — that is precisely the class of defect a human running tests locally will never see. The argument for the short wait was the flake underneath it, which is fixed: two ten-minute waits nested inside a three-minute kill, reproduced deterministically with zero browsers launched.
